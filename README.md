# 民谣翻译官 · 歌词里的心事

> 把每一句民谣，翻译成你没说出口的心事。

一个**民谣歌词解读类短视频个人 IP** 的完整生产仓库——不是某一个视频，而是一套能持续出片的「内容 + 流水线」。
第 1 期《第一眼》从 IP 设计到可发布的 720×1280 竖屏成片，全程在这里跑通过。

---

## 这个仓库能干什么

给你三样东西：**想得清楚的定位**、**写得出来的文案**、**跑得通的成片流水线**。

## IP 定位（一张表看懂）

| | |
|---|---|
| 出镜署名 | 笔澜（可全局替换成你的昵称） |
| 参考昵称 | 民谣翻译官 |
| 栏目名 | 歌词里的心事 |
| 一句话定位 | 把每一句民谣，翻译成你没说出口的心事 |
| 在做什么 | 拿任意一句民谣歌词，做成一期「把歌词翻译成人心」的口播短视频 |
| 差异化 | 乐评是**向外**讲歌（编曲/流派/创作背景）；这个号**向内照镜子**——讲你听歌时那点没说出口的感觉 |
| 核心打法 | 情绪共鸣。用第二人称把歌词照进观众自己的故事 |
| 目标受众 | 22–38 岁、城市独处、深夜听民谣，心里有漂泊 / 孤独 / 没讲出口情绪的人 |

## 成片生产 SOP

一期从零到能发布，按这个顺序跑：

```
① 写文案    钩子前置 → 亮歌词 → 拆情绪 → 落到观众自己 → 二选一互动
② 配音      文案粘进剪映 App「文本朗读」→ 导出 mp3
③ 对齐      python scripts/align_v3b.py     → 产出逐句真实时间轴 json
④ 合成      python scripts/gen_video_v2.py  → 出品 720×1280 竖屏 mp4
```

**第 ② 步是关键。** 本机所有在线 TTS 都不可用、离线语音也跑不动，剪映的文本朗读是唯一又自然又免费的音源（原因见下面踩坑清单）。

## 脚本用途对照

| 脚本 | 作用 | 状态 |
|---|---|---|
| `gen_video_v2.py` | 主线合成：交叉溶解转场 + 逐句吸附字幕 + 歌词卡 / 栏目卡 + 轻氛围 BGM | ✅ 推荐 |
| `align_v3b.py` | ffmpeg 静音检测 + 碎片合并（gap<0.45s）+ DP 单调匹配，输出精确到句的时间轴 | ✅ 推荐 |
| `gen_tts_robust.py` | 剪映不可用时的兜底：每段独立子进程调用本机离线语音 | 备用 |
| `gh_search.py` | 动手前先搜 GitHub 有没有成熟现成方案 | ✅ 通用工具 |
| `legacy/*` | 迭代存档（初版合成、真人声版、剪映版、三版对齐、PS 配音脚本） | 存档，不再维护 |

> `gh_search.py` 也能单独当工具用：`python scripts/gh_search.py "关键词" --min-stars 1000`

## assets/ 为什么不进 git

`assets/` 里装的是**生产物**：成片 mp4（每个 1.7–5.7 MB）、背景图、音频、歌词卡、抽帧。它们体积大、且都能由上面的脚本重新生成，所以被 `.gitignore` 排除。第一次 clone 这个仓库时这里会是空的，跑一遍流水线就有了。

## 踩过的坑（真干过才知道）

1. **在线 TTS 全线不通**：edge_tts / gTTS 都被网络拦截，别浪费时间。剪映文本朗读是唯一稳且自然的方案。
2. **本机离线语音会卡死**：System.Speech / pyttsx3 在无音频设备的沙箱里直接挂住。兜底脚本改成"每段一个新进程 + 超时重试"才跑通。
3. **moviepy 的 ImageMagick 依赖**：做中文文字必炸。改成用 PIL 先把歌词卡 / 字幕渲成 PNG 再合成，绕过它。
4. **字幕和配音对不上**：按字数比例估时间必然漂。最终靠 ffmpeg silencedetect 找出真实停顿，再用 DP 单调匹配强制锚定到句。
5. **前 3 秒别自我介绍**：初版开场"我是笔澜…"，陌生人刷到听到的是"你是谁"，而不是"这跟我有什么关系"。改版第一句直接上情绪钩子。
6. **推 GitHub 要先开代理**：本机走 Clash（127.0.0.1:7897），git 已配好对该域名走此代理；代理没开就推不动。
