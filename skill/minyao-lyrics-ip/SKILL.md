# 民谣歌词解读栏目 IP 生产

## Overview

把任意一首民谣的某一句/一段歌词，制作成一期"把歌词翻译成人心"的竖屏口播短视频。核心打法不是乐评（讲编曲/流派/创作背景），而是**情绪共鸣**——用第二人称把歌词照进观众自己的故事，完成"我懂你听歌时的那点感觉"的人设。

整套流程是半自动的：本技能负责产出栏目化文案与画面/字幕合成方案；配音由用户在剪映 App 的"文本朗读"生成（免费、自然、无需 API），再把 mp3 交回，由合成步骤产出成片。

## 何时使用

- 用户说"做一期 XX 歌的歌词解读""用 XX 那句词做一期""帮我出民谣解读视频脚本""这个栏目下一期讲什么"。
- 用户有"民谣翻译官 / 歌词里的心事"这类个人 IP 定位，需要可复用的栏目生产模板。
- 触发关键词：民谣、歌词解读、歌词翻译、口播脚本、第一眼 / 离别 / 故乡 / 青春 / 错过 / 爱而不得等情绪母题。

## 栏目定位（写文案前先对齐）

- 账号昵称建议：民谣翻译官；栏目名：歌词里的心事。
- 价值主张：把每一句民谣，翻译成你没说出口的心事。
- 调性：温柔、懂人心、有故事感、不矫情；深夜陪伴感。
- 受众：22–38 岁、城市独处深夜听民谣、有漂泊 / 孤独 / 未说出口情绪的人。
- 差异化：乐评教人"更懂歌"，这里教人"更懂自己"。

## 工作流

### 步骤 1 · 确定歌曲与情绪母题
明确本期要解读的：歌曲名 + 歌手 + 核心歌词（一句，精确）+ 情绪母题（离别 / 第一眼 / 故乡 / 青春 / 错过 / 爱而不得等）。若用户只给了情绪方向没给歌，从 references/情绪母题与选题库.md 中推荐 2–3 首并请用户选定。

### 步骤 2 · 生成栏目化口播文案
严格按 references/栏目模板与文案结构.md 的五环节模板产出：
1. **钩子前置**（0–3s，第一句即情绪钩子，用"你"第二人称戳痛点 / 共鸣，先钩住再自报家门）；
2. **亮歌词 + 拆解情绪逻辑**（字面意 → 为什么戳人 → 落到观众故事）；
3. **情绪递进**（怀念 → 心动 → 怅然 → 共鸣 → 行动欲，逐段更深）；
4. **歌词嵌入**（把原词当"连歌都证明"的证据，不炫技）；
5. **二选一互动结尾**（低决策成本，可争辩）。
文案须口语化、短句留白、无书面腔；全程"你"第二人称。

### 步骤 3 · 输出剪映可用文案
提供两份：
- **整段粘贴版**：可直接粘进剪映"文本朗读"（标点即节奏：逗号小停、句号大停）。
- **分段版**：按 8 段（钩子 / 怀念 / 心动 / 怅然 / 歌词① / 过渡+歌词② / 互动 / 下期点歌）拆分，每段落注【画面提示】，方便用户加歌词卡、也方便后续字幕对齐。
提醒用户：文案里占位昵称"笔澜 / 民谣翻译官"需替换成自己的账号名；多音字（如"马頔"读作 mǎ dí）在剪映里可能需手动校正。

### 步骤 4 · 生成画面素材提示词
按民谣深夜氛围风格（暖橘 + 深蓝夜色、电影感、无文字、9:16 竖屏）为每段生成 1 张 ImageGen 提示词，对应歌词意象。风格与尺寸规范见 references/成片生产流程.md 的"画面提示词"节。

### 步骤 5 · 对接配音与成片合成
1. 用户用剪映"文本朗读"选温柔女声、导出 mp3（建议 1.0–1.1x 语速），交回本环境。
2. 按 references/成片生产流程.md 用 ImageGen 出图 + PIL 渲染字幕 / 歌词卡 + moviepy 合成竖屏 720×1280 成片（交叉溶解转场、字幕严格对齐配音真实停顿、轻钢琴 BGM）。
3. 交付 mp4。

> 关键约束（来自实测）：本环境在线 TTS（微软 / Google）被网络策略拦截、本机离线语音在无音频设备会话中会卡死，**不可用**；剪映 App 文本朗读是当前最稳的配音方案，必须由用户侧完成。第 1 期实测成片 = 剪映 AI 女声 + 氛围画面 + 逐句字幕 + 歌词卡，效果自然。
