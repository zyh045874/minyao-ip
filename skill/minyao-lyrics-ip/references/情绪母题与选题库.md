## 30 个可拍选题（已避开第 1 期用过的《程艾影》《南山南》）

1. 赵雷《成都》— 离别 / 城市记忆："和我在成都的街头走一走，喔哦，直到所有的灯都熄灭了也不停留"。你离开的不是一座城，是那盏曾为你亮着的灯。
2. 李志《关于郑州的记忆》— 旧地 / 爱情："关于郑州我知道的不多，为了爱情曾去过那里"。一座城市，因为一个人，从此有了心跳。
3. 毛不易《一荤一素》— 亲情 / 思念母亲："月儿明，风儿轻，可是你在敲打我的窗棂"。妈妈走后，连风声都像她在叫我回家吃饭。
4. 老狼《同桌的你》— 青春 / 初恋："明天你是否还想起，昨天你写的日记"。青春里那个人，连日记都成了不敢翻开的秘密。
5. 赵雷《理想》— 理想 / 现实："一个人住在这城市，为了填饱肚子就已精疲力竭"。成年人的崩溃，是从不好意思再谈理想开始的。
6. 宋冬野《安和桥》— 青春逝去 / 错过："我知道，那些夏天就像青春一样回不来"。有些夏天和有些人，注定只能留在记忆里。
7. 陈粒《奇妙能力歌》— 爱而不得："我看过沙漠下暴雨，看过大海亲吻鲨鱼，看过黄昏追逐黎明，没看过你"。见过世间所有奇迹，唯独没见过和你在一起。
8. 赵雷《妈妈》— 亲情 / 亏欠："你老了对不对，我还没能成为你的骄傲"。最怕妈妈变老，而我还没来得及让她骄傲。
9. 万晓利《这一切没有想象的那么糟》— 自愈 / 安慰："我知道一切都没有那么糟"。在最难的时候告诉自己还行，就是最大的勇敢。
10. 陈鸿宇《理想三旬》— 孤独 / 独处："就老去吧，孤独别醒来"。一个人也能把日子过成诗，只是偶尔怕黑。
11. 房东的猫《云烟成雨》— 暗恋 / 守护："我多想再见你，哪怕匆匆一眼就别离"。哪怕只能匆匆一眼，也想再确认你还安好。
12. 宋冬野《斑马，斑马》— 旧人 / 受伤离开："斑马斑马，你不要睡着啦，再给我看看你受伤的尾巴"。有些人受了伤还笑着，你却只能看着他走。
13. 李志《梵高先生》— 孤独 / 不被理解："我们生来就是孤独"。那些说不出口的委屈，最后都成了独自咽下的苦。
14. 赵雷《画》— 纯真 / 向往："画一个姑娘陪着我，再画个花边的被窝"。成年人的童话，是画一个永远不走的她。
15. 毛不易《消愁》— 平凡 / 借酒："一杯敬朝阳，一杯敬月光"。敬得起生活，才扛得住平凡。
16. 赵雷《我们的时光》— 青春 / 自由："我们的时光，是无忧的时光"。最无忧的时光，是你还相信永远。
17. 花粥《二十岁的某一天》— 青春 / 迷茫："二十岁的某一天，我找不到工作的意义"。二十岁最慌的，是不知道活着为了什么。
18. 焦迈奇《我的名字》— 暗恋 / 小欢喜："我的名字这么暖，一定要出现在你的青春里"。暗恋的人，连名字都想塞进你的青春。
19. 房东的猫《美好事物》— 治愈 / 温柔："我欣喜遇见你的温柔，也感激曾并肩的那些年"。谢谢你来过，让我的岁月有了重量。
20. 赵照《当你老了》— 长久的爱 / 陪伴："当你老了，头发白了，睡意昏沉"。最深的爱，是想象你老了还愿陪在身边。
21. 老狼《睡在我上铺的兄弟》— 友情 / 青春："睡在我上铺的兄弟，无声无息的你"。那个陪你熬过青春的兄弟，如今散落在哪座城？
22. 宋冬野《董小姐》— 心动 / 遗憾："董小姐，你才不是一个没有故事的女同学"。每个人都曾遇过一个，名字叫起来就心疼的人。
23. 李志《这个世界会好吗》— 迷茫 / 追问："这个世界会好吗，从此不再有我的任何消息"。最无力的时候，连这个世界会不会好都不敢问。
24. 赵雷《阿刁》— 倔强 / 自由："阿刁，你总把自己打扮得像一位倔强的姑娘"。真正自由的人，是把苦难活成了倔强。
25. 陈鸿宇《历历万乡》— 故乡 / 远方："阅历了江山和人情，惊艳了岁月与时光"。走过万水千山才懂，最惊艳的还是家乡那缕炊烟。
26. 马頔《傲寒》— 爱情 / 承诺："傲寒，我们结婚吧，乘着最早的列车"。最浪漫的求婚，是把你的名字写进余生。
27. 毛不易《平凡的一天》— 平凡 / 知足："这是最平凡的一天啊，你也想念吗"。最幸福不过，平凡的一天，有个人让你想念。
28. 水木年华《一生有你》— 青春 / 陪伴："多少人曾爱慕你年轻时的容颜，可知谁愿承受岁月无情的变迁"。容颜会老，愿陪你变老的人才最珍贵。
29. 陈粒《易燃易爆炸》— 自我 / 被误解："你以为我天性温良，你以为我不敢反抗"。别把我的温柔，错当成好欺负。
30. 毛不易《像我这样的人》— 平凡 / 不甘："像我这样优秀的人，本该灿烂过一生"。每个平凡的人心里，都藏着一个不甘的自己。

## 选题使用建议

- 每周按"情绪母题"循环选歌（漂泊→爱情→故乡→成长→遗憾→和解），避免审美疲劳。
- 同一首歌可换三种切入角度：创作背景 / 听众故事 / 时代情绪。
- 互动形式轮换：点歌 / 二选一 / 征集故事 / 翻唱接龙。
- 评论区置顶"下期点歌"，高赞提名直接当选题，形成 UGC 正循环。
